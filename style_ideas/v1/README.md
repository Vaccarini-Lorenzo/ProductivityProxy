# ProductivityProxy UI concepts v1

Each image is a 2x2 desktop UI concept sheet for the new semantics:

- Settings page: proxy start/stop, port, auth, LAN.
- Modes page: select current mode, create/edit/delete modes.
- Policy page: create/edit/delete policies, with the node/operator canvas.
- Node page: create/edit/delete custom Python nodes.

Generated concepts:

1. `style_01_dark_command_center.png` — dark command-center developer tool.
2. `style_02_light_productivity.png` — clean light productivity SaaS.
3. `style_03_ide_flow_builder.png` — IDE-inspired policy flow builder.
4. `style_04_glass_focus.png` — premium glass/focus interface.

Prompt files are kept next to the images for iteration.

These are exploration images only. They are not implementation specs yet.
