# Style idea generation prompts

Source screenshots are in `style_ideas/screenshots/`.

Each image edit prompt asks for five distinct alternatives while preserving the current screen content and layout.

## Shared direction

Redesign the supplied ProductivityProxy screenshot as a desktop app UI concept. Preserve the exact screen purpose, rough information hierarchy, left sidebar navigation, top save action, panels/forms/editor structure, and all important labels. Do not include browser chrome or people. Make the result look like a real product screenshot, not a poster. Improve polish, spacing, typography, contrast, accessibility, and component states. Avoid simply copying the current neon terminal style. The returned five images should explore clearly different visual styles: clean light productivity dashboard, premium dark command center, frosted glass/aurora, soft clay/neumorphic, and modern enterprise material.
